TWO WAYS

御社のPRに合わせて、2つの組み方から選べます

PRの設計とメディア対応は御社のまま。どかんは、飲食店とのコラボの部分を担います。

TYPE A

御社のスタッフと一緒にプランニング

企画の段階から参加し、コラボの切り口や店舗選び、発表のタイミングを、御社のスタッフと一緒に設計します。

COLLABORATION

PRのネタになる、3つのコラボの型

メニューをつくって終わりにせず、メディアやSNSで取り上げられることを前提にコラボを組み立てます。

TYPE 01

話題化コラボ

新商品の発売や季節の需要に合わせて、人気店とコラボメニューをつくり、ニュースとSNSの話題をつくります。

TYPE 02

社会啓発コラボ

食や健康、地域、環境などのテーマを、飲食店で「食べる体験」に置きかえて、身近に伝えます。

TYPE 03

食品以外の企業・IPとのコラボ

食品以外の企業やキャラクター・コンテンツも、メニューや店内の演出を通じて、生活者との接点をつくれます。

FAQ

よくあるご質問

費用はどのくらいかかりますか？

組み方、コラボの内容、店舗数、期間によって変わります。ご要望を伺ったうえで、個別にお見積りします。

プレスリリースやメディア対応は、どちらが担当しますか？

原則として御社にご担当いただきます。コラボの内容やお店の情報など、発信に必要な素材はどかんからお渡しします。

クライアントとのやりとりは、どうなりますか？

御社のご方針に合わせて決めます。クライアントとの窓口を御社に一本化したうえで、どかんはお店側の調整に専念することもできます。

提案前の段階でも相談できますか？

はい。「この商品で、こういうお店と組めそうか」といった段階から、実現できそうな形をお返しします。

お店の業態やエリアを指定できますか？

はい。ご希望の業態・客層・エリアを伺い、リレーション店舗をベースに、それ以外のお店も含めて合うお店をご提案します。

どのくらい前に相談すればよいですか？

メニュー開発やお店の準備があるため、実施のおよそ3か月以上前のご相談をおすすめしています。時期が近い場合も、まずはご相談ください。

飲食店コラボについて、お気軽にご相談ください
